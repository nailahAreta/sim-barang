# SIM-Barang

## Deskripsi Proyek

SIM-Barang (Sistem Pengelolaan Inventaris Barang Jurusan) adalah sistem yang digunakan untuk mencatat, mengelola, dan memantau data inventaris barang atau aset jurusan dan laboratorium.

## Konsep HTTP

HTTP (Hypertext Transfer Protocol) merupakan protokol yang digunakan untuk komunikasi antara client dan server dalam sebuah aplikasi web.

### HTTP Request

HTTP Request adalah permintaan yang dikirimkan oleh client kepada server. Contohnya ketika pengguna membuka halaman website atau mengirimkan data melalui formulir.

### HTTP Response

HTTP Response adalah balasan yang diberikan oleh server setelah menerima dan memproses request dari client.

## Tujuan

Project SIM-Barang dibuat sebagai studi kasus praktikum Pemrograman Web untuk mempelajari pengembangan aplikasi web secara bertahap menggunakan HTML, CSS, JavaScript, PHP, dan MySQL.
